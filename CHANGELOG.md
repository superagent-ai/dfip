# Changelog

## 0.1.0 — public research preview

- Lightweight Python and command-line clients for authenticated Modal inference.
- Immutable checkpoint registry for Julia-1, Liquid d1-3B, Clef-Flash,
  PPLX-Decider v1.1 27B, and Security-One 27B, with native deployment defaults.
- Separate experimental CUDA graph, candidate-projection, adaptive admission,
  and shared-batching paths.
- Four-model manuscript and reproducible analysis of PPLX-Decider, Liquid,
  Clef-Flash, and the research-only GLiNER2.5-Decide adapter.
- Archived raw measurements, protocols, source snapshots, numerical audits,
  failed attempts, and serving request accounting.
- CPU tests and packaging checks for Python 3.10 and 3.12.

This preview is intended for evaluation and research. It does not establish
production readiness, universal acceleration, or confidence equivalence for
every experimental path. The manuscript remains a review draft.
